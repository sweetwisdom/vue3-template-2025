# GitLab仓库文件视图组件说明

## 组件概述

基于Vue3 + Ant Design Vue开发的GitLab仓库文件视图组件，提供完整的仓库文件浏览、分支切换、文件预览等功能。支持Monaco Editor代码编辑器，能够预览多种文件类型。

## 技术栈

- **前端框架**: Vue 3 (Composition API)
- **UI组件库**: Ant Design Vue 4.x
- **代码编辑器**: Monaco Editor
- **样式框架**: UnoCSS + SCSS
- **HTTP客户端**: Axios
- **构建工具**: Vite

## 组件架构

```
src/
├── api/

│   ├── FileDirTree.vue       # 文件树组件
```

## 核心组件说明

### 1. BranchSelector.vue - 分支选择器

**功能**: 提供分支和提交记录的选择功能

**主要特性**:
- 分支下拉选择（支持分页加载）
- 提交记录选择（显示提交信息、作者、时间）
- 自动加载默认分支和最新提交
- 支持分支和提交切换事件

**Props**:
- `appId`: 应用ID（必填）

**Events**:
- `branch-change`: 分支切换事件
- `commit-change`: 提交切换事件

### 2. FileDirTree.vue - 文件树组件

**功能**: 展示仓库文件树形结构

**主要特性**:
- 动态加载文件树数据
- 支持文件夹展开/收起
- 文件选择事件
- 刷新功能
- 懒加载支持

**Props**:
- `appId`: 应用ID（必填）
- `selectedCommit`: 选中的提交ID（必填）

**Events**:
- `file-select`: 文件选择事件

### 3. FilePreview.vue - 文件预览组件

**功能**: 预览不同类型的文件内容

**主要特性**:
- 代码文件：Monaco Editor预览
- 图片文件：图片预览
- 文本文件：文本预览
- 工具栏：下载、复制路径
- 文件信息显示（大小、类型等）

**Props**:
- `appId`: 应用ID（必填）
- `currentFile`: 当前选中的文件对象
- `selectedCommit`: 选中的提交ID（必填）

**Events**:
- `file-change`: 文件内容变化事件

### 4. MonacoEditor.vue - 代码编辑器

**功能**: Monaco Editor的Vue封装组件

**主要特性**:
- 支持多种编程语言
- 代码高亮
- 可配置选项
- 响应式布局
- 只读模式支持

**Props**:
- `value`: 编辑器内容
- `language`: 编程语言
- `options`: 编辑器配置选项
- `height`: 编辑器高度

**Events**:
- `change`: 内容变化事件
- `update:value`: 双向绑定更新事件

## API接口说明

### 仓库管理接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| getAppBranch | GET | /repo/getAppBranch | 分页获取应用仓库分支列表 |
| getAppVersion | GET | /repo/getAppVersion | 获取应用仓库分支提交记录 |
| getFileTree | GET | /repo/getFileTree | 获取仓库文件结构 |
| getFileContent | GET | /repo/getFileContent | 获取文件内容（base64编码） |
| downloadFile | GET | /repo/downloadFile | 下载仓库文件 |

### 接口参数说明

**getAppBranch**:
- `appId`: 应用ID
- `pageIndex`: 页码
- `pageSize`: 每页大小

**getAppVersion**:
- `appId`: 应用ID
- `branchName`: 分支名称

**getFileTree**:
- `appId`: 应用ID
- `ref`: 提交ID
- `path`: 文件路径（可选，不传表示根目录）

**getFileContent**:
- `appId`: 应用ID
- `ref`: 提交ID
- `path`: 文件路径

## 使用方法

### 1. 安装依赖

```bash
pnpm add monaco-editor
```

### 2. 在页面中使用

```vue
<template>
  <div class="w-vw bg-gray-50">
    <div class="flex h-vh">
      <!-- 左侧文件树 -->
      <div class="w-80 bg-white border-r border-gray-200 flex-shrink-0">
        <file-dir-tree 
          :app-id="appId"
          :selected-commit="selectedCommit"
          @file-select="handleFileSelect"
        />
      </div>
      
      <!-- 中间内容区域 -->
      <div class="flex-1 flex flex-col bg-white">
        <!-- 分支选择器 -->
        <branch-selector 
          :app-id="appId"
          @branch-change="handleBranchChange"
          @commit-change="handleCommitChange"
        />
        
        <!-- 文件预览区域 -->
        <div class="flex-1 overflow-hidden">
          <file-preview
            :app-id="appId"
            :current-file="currentFile"
            :selected-commit="selectedCommit"
            @file-change="handleFileChange"
          />
        </div>
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import FileDirTree from '@/components/FileTree/FileDirTree.vue'
import BranchSelector from '@/components/FileTree/BranchSelector.vue'
import FilePreview from '@/components/FileTree/FilePreview.vue'

const appId = ref('your-app-id')
const selectedCommit = ref('')
const currentFile = ref(null)

// 事件处理函数...
</script>
```

### 3. 配置环境变量

在`.env`文件中配置API基础URL：

```env
VITE_API_BASE_URL=http://your-api-domain/api
```

## 样式定制

组件使用UnoCSS和SCSS，支持以下样式定制：

### UnoCSS类名
- `w-vw`: 视口宽度
- `h-vh`: 视口高度
- `flex`: flexbox布局
- `bg-gray-50`: 背景色
- `border-r`: 右边框

### 自定义样式
可以通过SCSS变量和类名覆盖默认样式：

```scss
.custom-tree {
  .ant-tree-switcher {
    margin-right: -10px;
    padding: 2px 2px;
  }
}
```
