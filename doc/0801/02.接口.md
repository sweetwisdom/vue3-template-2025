


# v8.20/应用仓库管理

## GET 分页获取应用仓库分支列表

GET /repo/getAppBranch

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|appId|query|string| 是 |none|
|pageIndex|query|string| 是 |none|
|pageSize|query|string| 是 |none|

> 返回示例

> 200 Response

```json
{
  "code": "000000",
  "data": {
    "data": [
      {
        "appId": "1952934473607139329",
        "repoId": "3",
        "branchName": "main"
      },
      {
        "appId": "1952934473607139329",
        "repoId": "3",
        "branchName": "new-feature"
      },
      {
        "appId": "1952934473607139329",
        "repoId": "3",
        "branchName": "newBranch"
      }
    ],
    "total": 3,
    "pageIndex": 1,
    "pageSize": 10
  },
  "msg": "success"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

## GET 获取仓库文件结构

GET /repo/getFileTree

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|appId|query|string| 是 |none|
|ref|query|string| 是 |为“获取应用仓库分支提交记录”的commitId|
|path|query|string| 是 |不传表示查询根目录结构|

> 返回示例

> 200 Response

```json
{
  "code": "000000",
  "data": [
    {
      "id": "d564d0bc3dd917926892c55e3706cc116d5b165e",
      "name": "aaa",
      "type": "tree",
      "path": "aaa",
      "mode": "040000"
    },
    {
      "id": "015eb20675738af908765481bab87872ab7b41b8",
      "name": "README.md",
      "type": "blob",
      "path": "README.md",

    },
    {
      "id": "f015e5530584e5450fb681112d71d86c8ecd0e1b",
      "name": "hello.txt",
      "type": "blob",
      "path": "hello.txt",
      "mode": "100644"
    }
  ],
  "msg": "success"
```
